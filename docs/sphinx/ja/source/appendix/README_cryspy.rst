CrySPY
======

SUMMARY
-------

Python で書かれた結晶構造探索ツール。ランダム探索、進化的アルゴリズム、
ベイズ最適化、LAQA などの構造生成手法と、VASP・Quantum ESPRESSO・OpenMX
などの外部エネルギー計算コードを組み合わせて安定構造を探索する。
