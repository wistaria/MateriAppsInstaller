ALAMODE
=======

SUMMARY
-------

格子振動の非調和性を露わに考慮した原子間力定数を構築するプログラム
パッケージ。VASP・Quantum ESPRESSO などの第一原理計算や LAMMPS の結果から
調和・非調和 force constant を推定し、フォノン分散・フォノン状態密度・
グリューナイゼン定数・フォノン間散乱・格子熱伝導率・有限温度の非調和フォノン
などを計算する。
