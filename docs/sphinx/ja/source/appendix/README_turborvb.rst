TurboRVB
========

SUMMARY
-------

固体から分子まで様々な多体系を高精度に扱える第一原理量子モンテカルロ
（QMC）パッケージ。共鳴原子価結合（RVB）波動関数に基づき、変分モンテ
カルロ（VMC）および格子正則化拡散モンテカルロ（LRDMC）計算を行う。
