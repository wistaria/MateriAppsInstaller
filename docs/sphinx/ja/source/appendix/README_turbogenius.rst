TurboGenius
===========

SUMMARY
-------

第一原理量子モンテカルロ（QMC）パッケージ TurboRVB の Python
ラッパー群。TurboRVB のジョブを Python から制御し、TurboWorkflows と
組み合わせることで VMC・LRDMC・構造最適化などのハイスループット QMC
計算を実現する。
