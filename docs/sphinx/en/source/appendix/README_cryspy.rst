CrySPY
======

SUMMARY
-------

CrySPY is a crystal structure prediction tool written in Python. It
searches for stable structures by combining structure generation (random
search, evolutionary algorithm, Bayesian optimization, LAQA, ...) with
external energy calculators such as VASP, Quantum ESPRESSO, and OpenMX.
