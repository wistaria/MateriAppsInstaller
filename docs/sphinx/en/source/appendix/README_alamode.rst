ALAMODE
=======

SUMMARY
-------

A program package for estimating harmonic and anharmonic interatomic force
constants of solids and analyzing lattice anharmonicity. Combined with
first-principles packages (VASP, Quantum ESPRESSO) or LAMMPS, it computes
phonon dispersion, phonon DOS, Gruneisen parameters, phonon-phonon scattering,
lattice thermal conductivity, and anharmonic phonons at finite temperature.
