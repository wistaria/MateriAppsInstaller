TurboGenius
===========

SUMMARY
-------

TurboGenius is a set of Python wrappers for the ab initio quantum Monte
Carlo package TurboRVB. It drives TurboRVB jobs from Python and, combined
with TurboWorkflows, enables high-throughput QMC calculations (VMC, LRDMC,
structure optimization, ...).
